# 熟悉生命與手繪插畫改版

狀態：2026-10-23依使用者要求完成，已正式發布並交叉驗證；證據見release-verification.md。

## 本輪選材

72是可玩生命情境數，每個世界9種。同一動物可在不同時間地點有不同故事。寒武與石炭冷門生命已移出目前目錄，改為當代海洋與森林；不把現生動物放進錯誤年代。大標題以孩子熟悉的動物家族與外形線索為主，拉丁名與具體物種放小筆記。原三個人類職業改為狗、馬、貓；蛇頸龍、鱷魚與白鷺鷥有完整替換故事。

8個世界為marine、woodland、jurassic、cretaceous、iceage、ancient、preindustrial、modern。所有即時內容集中在dist/lives-*.js，沒有保留冷門生物的dead runtime modules或舊流程。原研究與計畫只作附日期的歷史紀錄。

## 圖片與遊玩

每生命一張獨立imagegen插畫，奶油紙色、柔和藍綠、赭色與水彩繪本筆觸。逐批最多6張，完成命名、WebP轉換、肉眼檢查和manifest引用才進下一批。圖片用在首頁6個直接遊玩入口、揭曉、圖鑑、結果與兩種分享卡；分享卡保留完整身體構圖和結果QR。沒有以emoji、共用地球或同一圖重複冒充72種。

文字維持繁中／英文，四章與三結局、可關閉音樂、圖鑑備份及同起點分享。新目錄使用otherlife-save／formatotherlife，避免舊職業紀錄錯配為新動物，不讀舊模型也不遷移。
